# YEGOOM ARCADE 디자인 적용

디자인 원본: https://www.figma.com/design/GsjY0UHZUigVKDVbZMnKe2/YEGOOM-ARCADE?node-id=33-2

## 적용 범위

- 로그인, 첫 진입, 프로필, 랭킹, 공통 설정과 운영 화면.
- 기상·퇴근 예측/출제/대기/결과, 퀴즈 출제/문제/힌트/결과.
- 독심술사 로비/작성/준비/익명 추측/결과, 숫자 게임 로비/선택/준비/결과.
- PC에서도 기존 560px 최대 본문 폭 유지. 작은 화면용 간격과 글자 크기, 터치 영역, 키보드 포커스, 동작 줄이기 설정 반영.

`public/css/style.css`의 기존 구조 위에 `arcade.css`를 적용한다. 크림 배경, 게임별 파스텔 색상, 검은 테두리와 단단한 그림자를 공통 토큰으로 사용한다. 게임 영웅 이미지와 결과·대기 상태 표현은 `public/js/arcade.js`에 모았다.

서버/API/DB/채점 및 권한 규칙은 변경하지 않았다. 저장과 준비 완료는 별도 동작이며, 다른 사람의 정답은 서버가 공개한 상태에서만 표시한다. 시간 입력과 숫자 카드의 미확정 선택은 같은 회차의 자동 갱신 동안 보존한다.

## 자산

- `public/assets/arcade/*.webp`: 이번 디자인 작업에서 생성해 Figma에 사용한 고양이 일러스트 14종. 웹용으로 최대 960px, WebP로 최적화했다.
- `public/assets/arcade/icon-*.svg`: 같은 Figma 파일의 네이티브 아이콘에서 직접 내보낸 6종.
- `public/assets/fonts/`: Fontsource Variable 5.3.0의 Noto Sans KR/Outfit WOFF2 및 각 OFL 라이선스. `fonts.css`의 Unicode 범위별 로컬 로딩으로 외부 폰트 서비스와 만료되는 이미지 URL에 의존하지 않는다.

## 검증

```sh
npm ci
npm test
```

기존 D1 통합 테스트와 점수 경계 테스트에 더해, 실제 프런트엔드 모듈을 JSDOM에서 실행한다. 시간 초안 보존, 서버 점수 표시, 출제자 전용 입력, 기회 티켓, 숫자 선택 보존, 본인 답변 추측 제한, 확정 후 입력 잠금, 힌트 공개 상태를 검증한다. VM 모듈 플래그는 이 테스트의 ES module 실행에 필요하며 운영 앱에는 사용하지 않는다.

JSDOM은 화면 레이아웃을 렌더링하지 않는다. 이번 실행 환경에서는 브라우저의 로컬 미리보기 연결이 차단되어 실제 기기의 화면/터치 검수는 완료하지 못했다. 배포 전 320px·390px·PC에서 줄바꿈, 고정 탭바, 키보드, 모달, 이미지 로딩을 확인해야 한다.
