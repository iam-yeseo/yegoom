# YEGOOM ARCADE 디자인 적용

디자인 원본: https://www.figma.com/design/GsjY0UHZUigVKDVbZMnKe2/YEGOOM-ARCADE?node-id=33-2

## 적용 범위

- 로그인, 첫 진입, 프로필, 랭킹, 공통 설정과 운영 화면.
- 기상·퇴근 예측/출제/대기/결과, 퀴즈 출제/문제/힌트/결과.
- 독심술사 로비/작성/준비/익명 추측/결과, 숫자 게임 로비/선택/준비/결과.
- PC에서도 기존 560px 최대 본문 폭 유지. 작은 화면용 간격과 글자 크기, 터치 영역, 키보드 포커스, 동작 줄이기 설정 반영.

`public/css/style.css`의 기존 구조 위에 `arcade.css`를 적용한다. 크림 배경, 게임별 파스텔 색상, 검은 테두리와 단단한 그림자를 공통 토큰으로 사용한다. 게임 영웅 이미지와 결과·대기 상태 표현은 `public/js/arcade.js`에 모았다.

서버/API/DB/채점 및 권한 규칙은 변경하지 않았다. 저장과 준비 완료는 별도 동작이며, 다른 사람의 정답은 서버가 공개한 상태에서만 표시한다. 시간 입력과 숫자 카드의 미확정 선택은 같은 회차의 자동 갱신 동안 보존한다.

## 자산

- `public/assets/arcade/*.png`: 사용자가 제공한 `PNG-originals.zip`의 고양이 일러스트 14종을 원본 그대로 사용한다. 알파 채널을 보존하고 `mix-blend-mode: multiply`를 제거해 배경색이 일러스트 색에 섞이지 않게 했다.
- `public/assets/arcade/icon-*.svg`: 같은 Figma 파일의 네이티브 아이콘에서 직접 내보낸 6종.
- `public/assets/fonts/TmoneyRoundWind*.woff2`: 사용자가 제공한 `01_otf.zip`의 티머니 둥근바람 Regular·ExtraBold를 WOFF2로 압축했다. 글리프 윤곽·문자 매핑·글자 폭은 원본과 동일하다. 한글 음절과 자모에만 적용한다.
  - Regular: 본문과 보조 설명(기존 CSS 100–599).
  - ExtraBold: 버튼·탭·제목·강조(기존 CSS 600–900).
- `Outfit Digits`는 기존 Outfit Variable 파일을 숫자 `0–9`에만 연결하는 별칭이다. 본문, 버튼, 입력, 점수, 날짜와 기록 등 모든 화면에서 숫자는 Outfit Variable로 표시한다.
- 기존 Noto Sans KR/Outfit WOFF2와 OFL 라이선스는 유지한다. 영문은 기존 서체와 굵기를 유지하고, 새 폰트에 없는 한글은 기존 폰트로 폴백한다. 모든 폰트는 로컬에서 제공한다.

## 검증

```sh
npm ci
npm test
```

기존 D1 통합 테스트와 점수 경계 테스트에 더해, 실제 프런트엔드 모듈을 JSDOM에서 실행한다. 시간 초안 보존, 서버 점수 표시, 출제자 전용 입력, 기회 티켓, 숫자 선택 보존, 본인 답변 추측 제한, 확정 후 입력 잠금, 힌트 공개 상태를 검증한다. VM 모듈 플래그는 이 테스트의 ES module 실행에 필요하며 운영 앱에는 사용하지 않는다.

이미지·폰트 교체 후 기존 테스트 7개를 통과했다. 로컬 Chrome에서 API 응답을 모킹해 로그인, 오전, 오후, 퀴즈, 독심술사, 숫자 게임, 프로필, 랭킹을 320px·390px·1280px에서 확인했다. 가로 넘침, 이미지 로딩, 브라우저 오류를 검사하고 실제 사용된 글꼴이 한글 Regular/ExtraBold, 영문 Noto Sans KR, 워드마크와 모든 숫자 Outfit으로 분리되는지 확인했다. PNG 14개는 첨부 원본을 유지한다. 새 WOFF2 두 파일은 원본 OTF의 글리프 윤곽·문자 매핑·글자 폭과 동일함을 검증했다. 실제 모바일 기기의 터치·키보드와 운영 API 검증은 이 로컬 화면 검사에 포함되지 않는다.
